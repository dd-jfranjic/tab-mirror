# Contributing

Bug reports are the most useful thing you can send. Please include your Chrome version, both operating systems, what you did and what you saw.

For a code change, open an issue first so we can agree on it. Then:

1. Run `npm test` and `npm run test:e2e`. Both must pass.
2. Add a test that fails without your fix.
3. Keep the change to one thing.

Tab Mirror has no server on purpose, and it stays that way. Changes that add a server, an account or data collection won't be accepted.

Issues in English or Croatian are both fine.
